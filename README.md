Retail Inventory Management System-SET 1

About the Project
This project is developed using MySQL to manage retail products, categories, suppliers, warehouses, and inventory stock details.

 Technologies Used
- MySQL
- SQL
- MySQL Workbench
  
 Database Tables
1. Category
2. Supplier
3. Warehouse
4. Product
5. Inventory

 Key Features
- Store and manage product details.
- Maintain supplier and warehouse information.
- Track inventory quantities.
- Set reorder levels.
- Maintain data integrity using SQL constraints.
- Perform INSERT, UPDATE, DELETE, and SELECT operations.

 Normalization
The database follows 1NF, 2NF, and 3NF to reduce data redundancy and improve data consistency.
